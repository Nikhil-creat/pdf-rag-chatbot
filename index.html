Support & help

  1. Tap the upload box (or drag a file onto it) and choose one or more PDF or .txt files — under 20MB each.
  2. Wait for each file to show a page/word count on its spine — that means it's indexed.
  3. Type a question in the box at the bottom of the chat panel and tap ASK. The answer, with citations, appears above the chat.
  4. Tap any passage in the "Catalog Drawer" on the left to read it in full.

If something isn't working

  • Upload only accepts .pdf and .txt files — anything else is skipped with a message at the top of the screen.
  • Scanned/image-only PDFs have no selectable text, so nothing gets indexed from them.
  • If a file won't upload, try reloading the page once — a slow connection can stop the PDF engine from loading in time.
  • Your documents and chat stay in this browser only — reinstalling the app or clearing browser data will reset it. Use Reset session (top right) to start fresh anytime.
